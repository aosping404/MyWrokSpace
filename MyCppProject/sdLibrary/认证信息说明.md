# 科大讯飞离线语音合成SDK认证信息说明

## ⚠️ 重要提示

**你当前使用的是"离线语音合成（轻量级）Linux SDK"，需要使用"离线引擎托管平台"的认证信息，而不是"Websocket服务接口"的认证信息！**

## 问题诊断

### 当前错误
- **错误码**: 2003
- **错误信息**: "未发现应用"
- **原因**: 使用了错误的认证信息（Websocket服务接口的认证信息）

### 两种不同的平台

#### 1. 开放平台（在线服务）
- **用途**: 在线语音合成服务（Websocket接口）
- **认证信息**: 
  - APPID: `49a34dbc`
  - APISecret: `NWRjNWM3M2FkNWUyNDU2ZGU5MDU5ODY1`
  - APIKey: `d957cd12cb3b7831de439e45c80ad5c4`
- **❌ 不能用于离线SDK**

#### 2. 离线引擎托管平台（离线SDK）
- **用途**: 离线语音合成SDK（本地运行，无需联网）
- **认证信息**: 需要在离线引擎托管平台单独创建应用获取
- **✅ 必须使用这个平台的认证信息**

## 如何获取离线SDK的认证信息

### 步骤1: 登录离线引擎托管平台

1. 访问科大讯飞**离线引擎托管平台**（不是开放平台）
2. 使用你的账号登录

### 步骤2: 创建应用

1. 在平台中创建新应用
2. 选择"离线语音合成"能力
3. 填写应用信息

### 步骤3: 获取认证信息

创建应用后，平台会生成：
- **appID**: 应用ID（可能与开放平台的appID不同）
- **apiKey**: 离线引擎托管平台生成的唯一应用标识
- **apiSecret**: 离线引擎托管平台生成的唯一应用秘钥

### 步骤4: 配置到代码中

将获取到的认证信息填入 `src/hello_world_tts.cpp`:

```cpp
AIKIT_Configurator::builder()
    .app()
        .appID("你的离线平台appID")           // ⚠️ 使用离线平台的appID
        .apiSecret("你的离线平台apiSecret")   // ⚠️ 使用离线平台的apiSecret
        .apiKey("你的离线平台apiKey")         // ⚠️ 使用离线平台的apiKey
        .workDir("./")
    ...
```

## 常见问题

### Q1: 我没有离线引擎托管平台的账号怎么办？
**A**: 需要联系科大讯飞商务或技术支持，申请离线引擎托管平台的账号和权限。

### Q2: 离线平台的appID和开放平台的appID可以一样吗？
**A**: 通常不一样。离线引擎托管平台和开放平台是两个独立的平台，appID是各自平台生成的，不能混用。

### Q3: 我已经购买了发音人，还需要什么？
**A**: 
- 购买发音人只是授权了发音人资源
- 还需要在离线引擎托管平台创建应用并获取认证信息
- 需要下载发音人资源文件（.irf文件）并放到 `aisound/resource/` 目录

### Q4: 如何确认我使用的是正确的认证信息？
**A**: 
- 认证信息来自"离线引擎托管平台"（不是开放平台）
- 首次使用需要联网激活（获取license）
- 激活成功后可以在离线环境下使用

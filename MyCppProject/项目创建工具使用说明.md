# VSCode C++ 项目创建工具使用说明

本工具提供了两种方式来自动创建符合 Ubuntu VSCode C++ 编程的文件夹结构和配置文件。

## 使用方法

### 方法一：Bash 脚本（推荐）

```bash
# 交互式运行
./create_cpp_project.sh

# 或者直接指定项目名称（需要修改脚本支持参数）
./create_cpp_project.sh classTest
```

### 方法二：Python 脚本

```bash
# 交互式运行
./create_cpp_project.py

# 或者直接指定项目名称
./create_cpp_project.py classTest
```

## 创建的项目结构

运行脚本后，将创建以下结构：

```
项目名称/
├── .vscode/                    # VSCode 配置文件
│   ├── tasks.json              # 构建任务配置
│   ├── launch.json             # 调试配置
│   └── c_cpp_properties.json   # IntelliSense 配置
├── include/                    # 头文件目录
│   └── main.h                  # 示例头文件
├── src/                        # 源代码目录
│   └── main.cpp                # 示例源文件
└── README.md                   # 项目说明文档
```

## 配置文件说明

### tasks.json
- **C/C++: g++ build active file**: 构建当前活动文件（默认任务）
- **C/C++: g++ build project**: 构建整个项目

### launch.json
- **C/C++: g++ build and debug active file**: 调试当前活动文件
- **C/C++: g++ build and debug project**: 调试整个项目

### c_cpp_properties.json
- 配置 IntelliSense 路径和编译器设置
- 使用 C++17 标准
- 包含 `include/` 目录到搜索路径

## 使用示例

### 创建 classTest 项目

```bash
# 使用 Python 脚本
./create_cpp_project.py classTest

# 或使用 Bash 脚本（交互式）
./create_cpp_project.sh
# 然后输入: classTest
```

### 在 VSCode 中使用

1. 进入项目目录：
   ```bash
   cd classTest
   ```

2. 在 VSCode 中打开：
   ```bash
   code .
   ```

3. 构建项目：
   - 按 `Ctrl+Shift+B` 选择构建任务
   - 或使用播放按钮直接运行/调试

4. 调试：
   - 在代码中设置断点（点击行号左侧）
   - 按 `F5` 开始调试
   - 使用调试控制面板进行单步调试

## 特性

- ✅ 自动创建完整的 VSCode C++ 项目结构
- ✅ 配置好构建、调试和 IntelliSense 设置
- ✅ 包含示例代码文件
- ✅ 支持交互式和命令行参数两种方式
- ✅ 符合 Ubuntu/Linux 环境配置

## 注意事项

1. 确保已安装：
   - GCC 编译器 (`g++`)
   - GDB 调试器
   - VSCode C/C++ 扩展

2. 如果项目文件夹已存在，脚本会询问是否继续

3. 所有配置文件都已针对 Ubuntu/Linux 环境优化

## 项目概述

`my_visualization_tool` 是一个基于 ROS2 和 Qt 的实时图像可视化工具，用于机器人视觉应用开发。项目采用模块化设计，实现了 ROS2 消息处理、OpenCV 图像处理和 Qt 图形界面的无缝集成。

### 技术栈

- **ROS2 Jazzy**: 机器人操作系统框架
- **Qt 6**: 跨平台 GUI 框架
- **OpenCV**: 计算机视觉库
- **C++17**: 现代 C++ 标准

### 核心功能

- ✅ ROS2 图像话题订阅
- ✅ 实时图像显示
- ✅ OpenCV 图像处理
- ✅ 目标检测结果可视化（可扩展）
- ✅ Qt 图形界面

## 架构设计

### 整体架构

```
┌─────────────────────────────────────────────────┐
│              QApplication (main.cpp)            │
│                                                  │
│  ┌──────────────────────────────────────────┐  │
│  │         MainWindow (Qt UI)               │  │
│  │  ┌────────────────────────────────────┐  │  │
│  │  │      ImageViewer (图像显示)        │  │  │
│  │  └────────────────────────────────────┘  │  │
│  │  ┌────────────────────────────────────┐  │  │
│  │  │      ROS2Bridge (ROS2 桥接)        │  │  │
│  │  │  ┌──────────────────────────────┐  │  │  │
│  │  │  │  ROS2 Node (rclcpp::Node)    │  │  │  │
│  │  │  │  - Image Subscription        │  │  │  │
│  │  │  │  - Timer (spin_some)         │  │  │  │
│  │  │  └──────────────────────────────┘  │  │  │
│  │  └────────────────────────────────────┘  │  │
│  └──────────────────────────────────────────┘  │
│                                                  │
│  信号槽连接: ROS2Bridge → MainWindow → ImageViewer │
└─────────────────────────────────────────────────┘
```

### 数据流

```
ROS2 话题 (/camera/image_raw)
    ↓
ROS2Bridge::imageCallback()
    ↓
cv_bridge 转换 (sensor_msgs → cv::Mat)
    ↓
Qt 信号: imageReceived(cv::Mat)
    ↓
MainWindow::onImageReceived()
    ↓
ImageViewer::setImage()
    ↓
OpenCV Mat → QPixmap 转换
    ↓
Qt UI 显示
```

### 模块划分

1. **MainWindow**: 主窗口类，负责 UI 管理和组件协调
2. **ROS2Bridge**: ROS2 与 Qt 的桥接类，处理消息订阅和转换
3. **ImageViewer**: 图像显示组件，负责 OpenCV 与 Qt 的图像转换

## 类设计详解

### 1. MainWindow 类

**职责**: 主窗口管理、组件初始化、信号槽连接

**位置**: 
- 头文件: `include/my_visualization_tool/main_window.hpp`
- 实现文件: `src/main_window.cpp`

#### 类成员

```cpp
class MainWindow : public QMainWindow
{
    Q_OBJECT
    
private:
    Ui::MainWindow *ui;                          // UI 对象指针
    std::shared_ptr<rclcpp::Node> ros_node_;     // ROS2 节点
    std::unique_ptr<ROS2Bridge> ros_bridge_;     // ROS2 桥接对象
    std::unique_ptr<ImageViewer> image_viewer_;  // 图像查看器
    QTimer *status_timer_;                       // 状态更新定时器
};
```

#### 关键方法

**构造函数 `MainWindow(QWidget *parent)`**
- 初始化 UI
- 创建 ROS2 节点
- 创建 ROS2Bridge 和 ImageViewer
- 连接信号槽
- 启动状态更新定时器

**槽函数 `onImageReceived(const cv::Mat& image)`**
- 接收来自 ROS2Bridge 的图像信号
- 将图像传递给 ImageViewer 显示

**槽函数 `onDetectionReceived(const std::vector<Detection>& detections)`**
- 接收检测结果
- 更新状态标签
- 触发图像绘制

**槽函数 `updateRos2Status()`**
- 更新 ROS2 连接状态显示

#### 使用示例

```cpp
// 在 main.cpp 中
my_visualization_tool::MainWindow window;
window.show();
```

### 2. ROS2Bridge 类

**职责**: ROS2 消息订阅、图像转换、Qt 信号发送

**位置**:
- 头文件: `include/my_visualization_tool/ros2_bridge.hpp`
- 实现文件: `src/ros2_bridge.cpp`

#### 类成员

```cpp
class ROS2Bridge : public QObject
{
    Q_OBJECT
    
private:
    rclcpp::Node::SharedPtr node_;                    // ROS2 节点指针
    rclcpp::Subscription<sensor_msgs::msg::Image>::SharedPtr image_sub_;  // 图像订阅者
    rclcpp::TimerBase::SharedPtr timer_;              // ROS2 消息处理定时器
};
```

#### 关键方法

**构造函数 `ROS2Bridge(rclcpp::Node::SharedPtr node, QObject *parent)`**
- 创建图像订阅者（订阅 `/camera/image_raw`）
- 创建定时器定期调用 `rclcpp::spin_some()` 处理消息

**回调函数 `imageCallback(const sensor_msgs::msg::Image::SharedPtr msg)`**
- 使用 `cv_bridge` 将 ROS 图像消息转换为 OpenCV Mat
- 发出 `imageReceived` 信号

#### 信号

```cpp
signals:
    void imageReceived(const cv::Mat& image);
    void detectionReceived(const std::vector<Detection>& detections);
```

#### 线程安全说明

- ROS2 回调在 ROS2 线程中执行
- 通过 Qt 信号机制将数据传递到主线程（UI 线程）
- 确保线程安全

#### 使用示例

```cpp
// 在 MainWindow 中
ros_bridge_ = std::make_unique<ROS2Bridge>(ros_node_, this);
connect(ros_bridge_.get(), &ROS2Bridge::imageReceived,
        this, &MainWindow::onImageReceived);
```

## 关键代码解析

### 1. 主函数 (main.cpp)

```cpp
int main(int argc, char *argv[])
{
    // 1. 初始化 ROS2（必须在创建 Qt 应用之前）
    rclcpp::init(argc, argv);
    
    // 2. 创建 Qt 应用程序
    QApplication app(argc, argv);
    
    // 3. 创建主窗口
    my_visualization_tool::MainWindow window;
    window.show();
    
    // 4. 运行 Qt 事件循环（阻塞）
    int result = app.exec();
    
    // 5. 关闭 ROS2（在 Qt 应用退出后）
    rclcpp::shutdown();
    
    return result;
}
```

**关键点**:
- ROS2 初始化必须在 Qt 应用创建之前
- `app.exec()` 是阻塞调用，运行 Qt 事件循环
- ROS2 关闭在应用退出后执行

---

### 2. ROS2 消息处理机制

```cpp
// 在 ROS2Bridge 构造函数中
timer_ = node_->create_wall_timer(
    10ms, [this]() {
        rclcpp::spin_some(node_);  // 非阻塞处理消息
    });
```

**关键点**:
- 使用定时器定期调用 `spin_some()` 而非阻塞的 `spin()`
- 允许 Qt 事件循环同时运行
- 10ms 间隔提供良好的响应性

### 3. 图像格式转换

```cpp
// OpenCV Mat → Qt QPixmap
QPixmap ImageViewer::matToQPixmap(const cv::Mat& mat)
{
    cv::Mat rgb_mat;
    // BGR → RGB 转换（OpenCV 使用 BGR，Qt 使用 RGB）
    cv::cvtColor(mat, rgb_mat, cv::COLOR_BGR2RGB);
    
    // 创建 QImage（共享数据，不复制）
    QImage qimg(rgb_mat.data, rgb_mat.cols, rgb_mat.rows,
                rgb_mat.step, QImage::Format_RGB888);
    
    // 转换为 QPixmap
    return QPixmap::fromImage(qimg);
}
```

**关键点**:
- OpenCV 使用 BGR 颜色空间，Qt 使用 RGB
- QImage 可以共享 OpenCV Mat 的数据（零拷贝）
- 注意：确保 Mat 在 QImage 使用期间保持有效

## 线程安全与信号槽机制

### 线程模型

```
┌─────────────────┐         ┌─────────────────┐
│  ROS2 线程      │         │  Qt UI 线程      │
│                 │         │                  │
│  imageCallback  │  信号   │  onImageReceived │
│       ↓         │  ────>  │       ↓          │
│  emit signal    │         │  setImage()      │
└─────────────────┘         └─────────────────┘
```

### 线程安全原则

1. **UI 更新必须在主线程**
   - 所有 Qt 组件操作必须在 UI 线程
   - 通过信号槽机制从其他线程传递数据

2. **ROS2 回调在 ROS2 线程**
   - `imageCallback` 在 ROS2 线程执行
   - 不能直接操作 Qt 组件

3. **使用信号槽传递数据**
   - 信号槽是线程安全的
   - Qt 自动处理线程间数据传递

### 最佳实践

```cpp
// ✅ 正确：通过信号传递数据
void ROS2Bridge::imageCallback(...) {
    emit imageReceived(cv_ptr->image);  // 线程安全
}

// ❌ 错误：直接在回调中操作 UI
void ROS2Bridge::imageCallback(...) {
    image_viewer_->setImage(...);  // 线程不安全！
}
```

## 扩展开发指南

### 1. 添加新的 ROS2 订阅

**步骤**:

1. 在 `ROS2Bridge` 头文件中添加订阅者成员:
```cpp
rclcpp::Subscription<geometry_msgs::msg::Pose>::SharedPtr pose_sub_;
```

2. 在构造函数中创建订阅者:
```cpp
pose_sub_ = node_->create_subscription<geometry_msgs::msg::Pose>(
    "/robot/pose", 10,
    std::bind(&ROS2Bridge::poseCallback, this, std::placeholders::_1));
```

3. 实现回调函数:
```cpp
void ROS2Bridge::poseCallback(const geometry_msgs::msg::Pose::SharedPtr msg)
{
    // 处理消息
    emit poseReceived(msg->position.x, msg->position.y, msg->position.z);
}
```

4. 添加信号:
```cpp
signals:
    void poseReceived(double x, double y, double z);
```

5. 在 `MainWindow` 中连接信号:
```cpp
connect(ros_bridge_.get(), &ROS2Bridge::poseReceived,
        this, &MainWindow::onPoseReceived);
```

### 2. 集成目标检测（YOLO26）

**步骤**:

1. 在 `ROS2Bridge` 中添加检测处理:

void ROS2Bridge::imageCallback(const sensor_msgs::msg::Image::SharedPtr msg)

## 常见问题与调试

### 问题 1: 图像不显示

**症状**: 程序运行但图像不显示

**可能原因**:
1. 没有图像话题发布
2. 话题名称不匹配
3. 图像编码格式不支持

**解决方法**:
```bash
# 检查话题列表
ros2 topic list

# 检查图像话题
ros2 topic echo /camera/image_raw --no-arr

# 修改订阅话题（在 ros2_bridge.cpp 中）
image_sub_ = node_->create_subscription<sensor_msgs::msg::Image>(
    "/your_topic_name", 10, ...);
```

---

### 问题 2: 编译错误 - 找不到头文件

**症状**: `fatal error: 'xxx.hpp' file not found`

**解决方法**:
1. 检查 `CMakeLists.txt` 中的包含目录设置
2. 确保已 source ROS2 环境:
```bash
source /opt/ros/jazzy/setup.bash
```
3. 重新编译:
```bash
colcon build --packages-select my_visualization_tool
```

---

### 问题 3: 运行时崩溃 - 段错误

**症状**: 程序启动后立即崩溃

**可能原因**:
1. UI 文件未正确加载
2. 空指针访问
3. 线程安全问题

**调试方法**:
```bash
# 使用 GDB 调试
gdb ./install/my_visualization_tool/lib/my_visualization_tool/my_visualization_tool
(gdb) run
(gdb) bt  # 查看堆栈跟踪
```

---

### 问题 4: 图像显示延迟

**症状**: 图像更新缓慢，有延迟

**解决方法**:
1. 减少图像分辨率
2. 调整 ROS2 订阅队列大小:
```cpp
image_sub_ = node_->create_subscription<sensor_msgs::msg::Image>(
    "/camera/image_raw", 1, ...);  // 减小队列大小
```
3. 优化图像处理代码

---

### 问题 5: Qt 信号槽不工作

**症状**: 信号发出但槽函数不执行

**检查清单**:
1. 确保类继承自 `QObject` 并使用 `Q_OBJECT` 宏
2. 确保信号槽签名匹配
3. 检查连接是否成功:
```cpp
bool connected = connect(...);
qDebug() << "连接状态:" << connected;
```
